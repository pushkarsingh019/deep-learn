# Curriculum

Use this branch to start or resume a topic. The learner sees a clear path; source analysis remains legwork.

## Opening interview

Before surveying a new source or topic, hold one short, bounded exchange—two or three questions, not a questionnaire. Establish the learner's practical reason for learning this, and elicit stated prior knowledge of the subject and its prerequisites. Record disclosed background as `evidence: stated` learning records so the baseline can start ahead of ordinary language when warranted, and note any teaching preference in `Teaching Notes.md`. Keep the source as the anchor: stop asking once the mission and baseline are clear enough to author the on-ramp. Completion: the mission and any stated baseline exist as durable notes before the first lesson is written.

## Start from a supplied source

1. Run the opening interview. If the request is simply “learn this source,” use a short provisional mission and let later evidence sharpen it. Identify the source and the learner’s practical reason for learning it.
2. Survey the source completely enough to avoid a distorted curriculum. Inspect major claims, dependencies, methods, evidence, limitations, and appendices or tests. **The source survey is legwork**, not learner-facing exposition.
3. Put the dense factual inventory in `<Topic> - Source Map.md`, with exact page/section/equation or file/symbol/test anchors. Link this support note from the MOC; keep it out of the learner’s path unless needed.
4. Build a broad dependency map covering the in-scope source. In the MOC, compress it into a few phases and detail only the current neighborhood. Completion: every major source region belongs to a phase or is explicitly out of scope, without dumping the inventory into the MOC.
5. Determine the baseline from linked evidence. No record means start the on-ramp without mathematical or domain prerequisites.
6. Author and open one on-ramp lesson. After opening it, create up to two **outline-only** draft notes. Until the first checkpoint is reviewed, drafts contain purpose, dependencies, and source anchors—no exposition, notation, or exercises.

The supplied source remains primary. Add surrounding literature only when it clarifies context, fills a real gap, or becomes an explicit secondary learning goal.

## Start from a topic

1. Run the opening interview and establish a concrete mission.
2. Find authoritative primary sources before teaching factual content.
3. Create the same source map, compressed MOC, and on-ramp lesson.

## Resume

1. Locate the requested MOC; when several are active and the request is ambiguous, ask which one.
2. Read **Now**, the active lesson and checkpoint, the current curriculum phase, and relevant learning records.
3. Load cross-topic context only when it can change a prerequisite, analogy, or misconception.
4. Route to review, continue the on-ramp, request depth consent, promote the next lesson, or begin capstone work.

## Pacing

- The first lesson is complete prose; the next two are outline-only until evidence arrives.
- After each review, revise the next outline before making it active. Once the baseline is established, maintain up to two provisional full drafts if useful.
- Ask for technical-depth consent only when the on-ramp checkpoint is resolved. Put the choice in chat and **Now**, rather than turning the lesson into a background survey.

Completion: the MOC exposes one immediate action near its top, the active lesson fits the demonstrated baseline, and future material cannot pull attention away from the current checkpoint.
