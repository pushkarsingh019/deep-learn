# Cross-Topic Context

Build a temporary, inspectable view of relevant prior learning. Learning records are durable evidence; the current view is derived when needed.

## Retrieval

1. Frame the current decision: which prerequisite, analogy, contrast, application, or misconception could change this lesson?
2. Find notes with `type: moc`. Inspect their titles, topics, statuses, mission summaries, and main links; select plausible conceptual matches.
3. Search MOCs and learning records for the current concepts and important source synonyms.
4. From the strongest matches, inspect outgoing links and backlinks one hop. Follow another hop only when the first contains an explicit reason.
5. Retrieve the smallest evidence set that can support the teaching decision.

Use Obsidian CLI for properties, search, links, and backlinks when available; use filesystem search otherwise.

## Evidence order

1. capstone or reconstruction performance;
2. demonstrated learning record linked to an answer or implementation;
3. learner-stated prior experience;
4. an answer under revision;
5. a lesson note, which establishes exposure only.

Treat old, contradicted, or weak evidence as uncertain. Prior knowledge can help or bias learning, so use a cross-topic connection as a hypothesis until evidence supports its fit.

## Use and persistence

- State any assumption that changes the lesson and cite its note or block. The learner can confirm or correct it.
- Probe a critical uncertain prerequisite rather than silently relying on it.
- When a connection materially improves learning, write a sentence explaining the relationship and include the wikilink. Backlinks supply reverse discovery.
- Update or supersede the underlying learning record when the learner corrects the assumption.
- A valid retrieval result may contain no useful cross-topic context.

Completion: determine with linked evidence—or explicitly report no evidence—which prior knowledge is reusable, which prerequisite is uncertain, which misconception may interfere, and which connection improves the lesson.
