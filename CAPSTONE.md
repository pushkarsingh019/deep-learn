# Capstone

Create a capstone only when the learner requests it. Its specification comes from the original source, not from lesson wording.

## Source-grounded design

1. Reopen and rescan the anchor source. For a topic-led curriculum, rescan the authoritative source set recorded in the MOC.
2. Use the Source map and curriculum to define scope. Include material from the path actually pursued; remove material tied to deferred, skipped, or remaining lessons.
3. Show a concise included/excluded scope summary and resolve scope corrections before writing prompts.
4. Prefer suitable author-provided exercises, repository tests, replication targets, or source problems. Supplement them where they do not test the intended depth.
5. Create one or two short synthesis essays and an implementation exercise when the topic has a programmable core.
6. For each prompt, establish:
   - the source-grounded understanding it probes;
   - observable response features that would support or weaken that understanding;
   - why this task can expose those features.

## Audit before release

Verify every prompt and scoring criterion for:

- exact source provenance;
- inclusion in the pursued scope;
- coverage of central in-scope mechanisms;
- first-principles cognitive depth;
- a novel example, condition, constraint, or failure mode;
- dependence on target understanding rather than prose polish or incidental syntax;
- diagnostic power: plausible errors reveal distinguishable weak models.

Revise every failed item before presenting the capstone. Keep prompts unseen until the learner requests the assessment.

## Evaluation

1. Preserve essays and implementations exactly as submitted.
2. Evaluate with a source-specific analytic rubric. Report `strong evidence`, `partial evidence`, or `insufficient evidence` for each important dimension and cite response evidence.
3. Identify fragile intuitions, derivations, assumptions, and implementation choices.
4. Create targeted remedial lessons for actual weak areas.
5. Reassess with new tasks from the same source-grounded task family.

Completion: the assessment samples the pursued source independently of lesson phrasing, and each conclusion about understanding is backed by observable evidence.
